# D&D 公开图片仓库

本地目录：`D:\desktop\dnd\DndGithubImages`。

图片存放在 `images/` 中，建议按战役、地点或人物建立子文件夹。当前已收录 `芙蕾雅.png` 和 `1B6D4049126431735042E11710462A74.png` 两张图片，未部署 Cloudflare 图片站。

## 使用边界

- 按仓库所有者要求公开，所有人都可以浏览图片和提交历史。
- 使用不含 token 的 `raw.githubusercontent.com` 图片直链，玩家无需 GitHub 登录即可访问；国内网络的速度和可用性仍取决于实际线路。
- 不要把带临时 token 的 Raw 地址、GitHub 访问令牌或账号凭据填入 Owlbear 共享资料。
- “团队手记”插画页可以从 Owlbear 图库选择，或将下面的 HTTPS 图片直链填入“从链接导入”。

## 后续上传

将图片复制到 `images/` 后，可以让 Codex 检查、提交并推送到本公开仓库。源码、历史副本、凭据和无关资料不应混入图片目录。

GitHub 普通 Git 文件限制为单个文件 100 MiB；本仓库尚未配置 Git LFS。
