# D&D 私有图片仓库

本地目录：`D:\desktop\dnd\DndGithubImages`。

图片存放在 `images/` 中，建议按战役、地点或人物建立子文件夹。当前尚无图片，未部署 Cloudflare 图片站。

## 使用边界

- 这是 GitHub 私有仓库，只有有权限且登录的用户能浏览。
- 私有仓库的普通 Raw 图片地址不能作为玩家免登录访问的稳定图床链接。
- 不要把带临时 token 的 Raw 地址、GitHub 访问令牌或账号凭据填入 Owlbear 共享资料。
- “团队手记”插画页可以从 Owlbear 图库选择，或导入公开 HTTPS 图片直链。若以后需要所有玩家直接看仓库图片，需要另行选择公开发布方式。

## 后续上传

将图片复制到 `images/` 后，可以让 Codex 检查、提交并推送到本私有仓库。源码、历史副本、凭据和无关资料不应混入图片目录。

GitHub 普通 Git 文件限制为单个文件 100 MiB；本仓库尚未配置 Git LFS。
